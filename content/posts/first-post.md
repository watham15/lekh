I've always wanted somewhere to write down what I'm learning, what I'm building, and whatever else I'm caught up in at the moment. Looks like this is that place.

### How I got here

My introduction to static site generators (SSGs) came from an acquaintance on Telegram whose documentation site was built with Hugo. It looked clean and fast, and it got me curious.

I started with Jekyll. It's a lovely tool, and I'd used it before, but that was months ago and honestly, I lost the will to maintain it. So I came back to the idea and tried Hugo this time, and here we are.

### What to expect

- **Things I'm learning:** notes and write-ups, partly so I understand them better by explaining them.
- **Technical posts:** walkthroughs, bugs I've run into.
